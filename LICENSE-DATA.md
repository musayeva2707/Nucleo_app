# Data licenses

Which files carry which license. Bundling these in an app does not require open-sourcing the app's code, but the credit lines must stay visible (the app shows them in Codex → Sources and in the ending credits).

| File | Contains | Source | License |
|---|---|---|---|
| `app/src/main/java/uz/nucleo/content/Elements.kt` | Cosmic origin of each element | Jennifer Johnson, Ohio State University, "Origin of the Elements in the Solar System" | CC BY-SA 4.0 (this adaptation is also CC BY-SA 4.0) |
| `app/src/main/java/uz/nucleo/content/Elements.kt` | Mass, category, state, discovery year | PubChem Periodic Table, National Library of Medicine (NCBI) | No restrictions; acknowledgment requested |
| `app/src/main/java/uz/nucleo/content/Elements.kt` | Visible emission lines (approximate) | NIST Atomic Spectra Database | Public access |
| `app/src/main/java/uz/nucleo/content/Galaxies.kt` | Galaxy10 class names and folding | Galaxy10 DECaLS (H. W. Leung & J. Bovy; labels from Galaxy Zoo) | CC BY 4.0 |
| `app/src/main/res/font/space_grotesk.ttf` | Font | Space Grotesk, Florian Karsten | SIL OFL 1.1 (`licenses/OFL-SpaceGrotesk.txt`) |
| `app/src/main/res/font/inter.ttf` | Font | Inter, The Inter Project Authors | SIL OFL 1.1 (`licenses/OFL-Inter.txt`) |

When real galaxy images are added, each image must show "Legacy Surveys / D. Lang (Perimeter Institute)" directly under it (CC BY 4.0).
